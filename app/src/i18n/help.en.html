Space: levels

Universe → Galaxy → Star system → Planet. Bottom centre shows where you are; click a link to go there.

Double-click or Enter — go inside · Ctrl+↑ — level up · keep scrolling past the zoom limit and the level changes by itself

V select and move · A add · L route · Del delete · Esc cancel · RMB tilt and turn · drag empty space — pan

In a galaxy, clicking empty space selects a sector: you can give it a name, a colour and a note.

Ctrl+F search planets, moons, systems and sectors · right-click → “Mark…” puts a coloured flag on a planet, system or sector.

Planet controls

LMB paint · RMB / Shift+LMB rotate · wheel — zoom

B brush · F fill · I eyedropper · E marker eraser · P point · R rotate

[ ] brush size · 1–9 palette type · M layer

Space stop the day cycle · , . phases · Del delete point

Ctrl+Z / Ctrl+Y undo/redo · Ctrl+S save · Ctrl+O open · Ctrl+1…5 windows

Generation, orbit, effects

Ctrl+8 “World generator”: a gallery with previews and search; world settings and add-ons (“Habitability” and others) on the left. Double-click a card to generate at once. Ctrl+G — another variant with the same settings.

A new generation clears the orbit and resets effects; the “Keep the orbit and effects as they are” tick in the gallery turns that off. Library types that are not used leave the palette when you generate.

Ctrl+6 “Orbit”: rings, debris, ships, stations, satellites, ring cities · Ctrl+7 “Effects”: snow, ash, rain, swarms… with density, speed and colour.

“File → Share…” packs a project, mods or themes into one .sspack file; “File → Open…” installs one.

Mods (JavaScript)

A folder in mods/ with mod.json and main.js:

export function activate(ss, mod) {
  ss.reg.terrains / effects / textures / buildings / poiKinds
  ss.reg.generators / genLayers / tools / windows / menus   // .register({id,...})
  ss.registerPack({...})        // data as in JSON
  ss.hooks.on('frame', ({dt,t}) => …)
  ss.hooks.on('cellInfo', (text, c) => text + ' …')   // filter
  ss.patch(ss.view, 'topR', (orig, c) => orig(c))      // wrap any function
  ss.particles.forLook('snow', {name, motion: 'fall', …})  // an effect in the “Effects” window
  ss.orbit.registerType({id, name, params, build})       // an object for the “Orbit” window
  ss.THREE, ss.scene, ss.view, ss.doc, ss.ui, ss.history
}

Events: frame, doc:loaded, doc:changed, palette:changed, selection:changed, tool:changed, prefs:changed, pois:changed, sky:tick, view:heights, mods:loaded, look:changed, fx:changed, generate:done, orbit:changed, registry:<kind>. Filters: cellInfo.

Translation: put i18n/en.json (Russian text → English text) into your mod folder; it is loaded automatically. A key with {} is a pattern. Without it your mod stays in its own language.
